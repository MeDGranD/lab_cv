Многоклассовая тонкозернистая (fine-grained) классификация изображений на 196 классов.  
Модели: предобученные CNN (ResNet50) и Vision Transformer (ViT-B/16) из `torchvision`, а также их кастомные имплементации, написанные с нуля.

---

## Датасет

**Источник:** [Stanford Cars Dataset](https://huggingface.co/datasets/tanganke/stanford_cars) (через зеркало HuggingFace `tanganke/stanford_cars`)

* **Количество классов:** 196 (Марка, модель, год выпуска. Пример: *Audi A5 Coupe 2012*).
* **Специфика:** Задача относится к классу *fine-grained classification*. Визуальные отличия между классами (например, разными годами выпуска одной модели) минимальны, что требует от сети высокой репрезентативной способности.
* **Объем данных:** 16 185 изображений (Разбивка train/test предоставляется датасетом из коробки).

## Часть 1 - Метрики

| Метрика | Роль | Обоснование |
|---------|------|-------------|
| **Accuracy** | Вспомогательная | Базовая метрика для понимания общего уровня предсказаний. |
| **Macro F1** | **Основная** | Усредняет F1 по всем 196 классам равномерно. Идеально подходит для множественной классификации, где важно оценивать способность модели распознавать как частые, так и редкие автомобили. |
| **Precision / Recall** | Диагностическая | Оценка смещений предсказаний модели (Macro-усреднение). |

**Функция потерь:** `CrossEntropyLoss`.

## Часть 2 - Базовые модели (pretrained torchvision)
Обучение предобученных на ImageNet моделей с заменой классификационной головы под 196 классов.

| Модель                | Тип архитектуры      | Заменяемый слой |
| ---------------------- | ----------- | ------ |
| resnet50 | CNN (Остаточные связи) | fc |
| vit_b_16 | Transformer (Self-Attention) | heads.head |

**Настройки**: AdamW (lr=1e-4 для ResNet, 5e-5 для ViT), 10 эпох, batch=32, базовые трансформации (Resize, CenterCrop, Normalize).

**Результаты (тестовая выборка)**

| Модель                | Train Accuracy      | Val Accuracy | Val Macro F1 |
| ---------------------- | ----------- | ------ | ------ |
| resnet50 | 99.74% | 83.5% | 0.8337 |
| vit_b_16 | 99.50% | 80.56% | 0.8065 |

**Вывод**: Обе модели быстро сходятся благодаря Transfer Learning, однако наблюдается сильное переобучение (Accuracy на трейне стремится к 100%, на валидации стагнирует в районе 80-84%).

## Часть 3 — Улучшенный базовый вариант

**Гипотезы и внедренные техники**

1. **Сложные аугментации данных**: Внедрение TrivialAugmentWide и RandomErasing для усложнения извлечения признаков и предотвращения прямого запоминания тренировочной выборки.
  
2. **Усиленная регуляризация**: Увеличение weight_decay до 5e-3 (L2-регуляризация).
  
3. **Адаптивный шаг обучения**: Использование планировщика CosineAnnealingLR для плавного затухания градиентного шага к концу обучения.

Результаты улучшенных моделей (10 эпох)

| Модель                | Val Accuracy      | Val Macro F1 | Δ Accuracy |
| ---------------------- | ----------- | ------ | ------ |
| resnet50 | 89.03% | 0.8892 | +5.53% |
| vit_b_16 | 89.37% | 0.8931 | +8.81% |

Вывод: Гипотезы полностью подтвердились. Внедрение техник регуляризации устранило переобучение и позволило моделям пробить порог в 85% точности. Обе архитектуры показали идентичный результат.

## Часть 4 — Кастомная реализация алгоритмов с нуля

**4a. Архитектуры**

* **Custom Advanced ResNet**: Обучаемая с нуля сеть на базе логики ResNet50 (каскады сверток 1x1, 3x3, 1x1 в блоках Bottleneck + Skip Connections). ~25М параметров.
  
* **Custom Vision Transformer**: Реализован механизм Patch Embedding, CLS-token, Positional Encoding и блоки Трансформера (Multi-Head Self Attention + MLP).

**4b–4j. Результаты и сравнение с базовыми моделями (10 эпох)**

| Модель                | Инициализация      | Пайплайн (Данные) | Val Accuracy |
| ---------------------- | ----------- | ------ | ------ |
| ViT-B/16 | Pre-trained | Улучшенный | 89.37% |
| ResNet-50 | Pre-trained | Улучшенный | 89.03% |
| Custom ResNet50 | Random (с нуля) | Базовый | 4.30% |
| Custom ResNet50 | Random (с нуля) | Улучшенный | 2.70% |
| Custom ViT | Random (с нуля) | Базовый | 1.18% |
| Custom ViT | Random (с нуля) | Улучшенный | 2.08% |

**Аналитический вывод по имплементации с нуля**

Низкие показатели (1-2%) обусловлены фундаментальными ограничениями глубокого обучения при дефиците данных (~8 тыс. тренировочных картинок):

1. **Избыточная параметризация**: Глубокие сети со случайными весами склонны к переобучению под шум на малых датасетах.

2. **Индуктивное смещение (Inductive Bias)**: Сверточная сеть (Custom ResNet50) достигла 4.30% точности, тогда как Custom ViT не превысил 2.08%. Свертки изначально ищут локальные пиксельные паттерны. Трансформеры лишены этого априорного смещения, и для понимания 2D-геометрии объектов им требуются данные масштаба ImageNet.

3. **Негативное влияние сложных аугментаций**: Для моделей, обучаемых с нуля, искажения (стирание областей) на старте лишь замедляют извлечение первичных признаков.

Доказана безальтернативность парадигмы Transfer Learning для сложных CV-задач.

## Визуализация и Интерпретируемость (Explainable AI)

Для обеспечения прозрачности принятия решений в ноутбук интегрированы инструменты XAI.

**1. Качественный анализ ошибок (Error Analysis)**
   
Модель извлекает неверно классифицированные изображения из тестового лоадера. Анализ подтвердил, что сеть не допускает "грубых" ошибок, путая исключительно родственные классы автомобилей (например, седаны Acura RL и Acura TSX одного года выпуска), либо ошибаясь на ракурсах без явных отличительных знаков бренда.

**2. Тепловые карты внимания (Grad-CAM)**

Использование Gradient-weighted Class Activation Mapping для визуализации зон, на которые опирается сверточная нейросеть при принятии решений.

Алгоритм успешно подсвечивает критически важные для fine-grained классификации элементы: радиаторные решетки, формы фар и колесные арки, игнорируя фоновый шум.
